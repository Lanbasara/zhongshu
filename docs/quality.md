# 可靠性、访问体验与性能

这些质量要求随能力首次出现就验收；没有“功能先完成，最后再补稳定性”的阶段。当前产品已有公开版本接口与私人登录入口；两端有限原生实验不代表 Agent 浏览器路径、网络恢复与性能已验收。协议归 [ADR 0004](adr/0004-recoverable-communication.md)，这里维护可观察结果与验证条件。

## 必须成立的行为

| 场景 | 用户应观察到的结果 |
| --- | --- |
| 命令受理后响应丢失，再次提交 | 核对同一操作，不产生第二次派发；原生结果无法确认时明确待核实 |
| 输出中断网、重复补发、游标过期 | 已保存内容不丢、不重复显示；缺口通过补发或快照恢复 |
| 页面关闭、切换对话、Android 后台或页面回收 | 服务端工作继续；重新打开恢复同一对话，展示真实运行或等待状态 |
| 应用或原生进程中断 | 依据可核实事实恢复；无法继续的工作明确失败或待核实，不能假装完成 |
| 两端回答同一问题或处理同一审批 | 一次有效处理，另一端看到结果；旧请求失效 |
| 退出、会话过期、恢复旧页面 | 私有接口和对应更新流失效；不再暴露新的私有内容 |
| 旧历史加载、持续输出、切换页面并发 | 阅读锚点稳定，旧响应不覆盖新页面；离开后释放请求与订阅 |
| 慢客户端、多标签页、长时间运行 | 队列、内存与连接数量有界；超限有可恢复的明确处理 |
| 手机中文输入、键盘、附件与发送失败 | 无误发送、无输入丢失；输入框可见，焦点与操作反馈连续 |

Android 页面可能被冻结或丢弃，后台计时器与连接不能成为可靠性前提；验收重点是远端持续运行和返回前台后的恢复。[浏览器生命周期](https://developer.chrome.com/docs/web-platform/page-lifecycle-api)

## 起始性能预算

以下是工程建议目标，**没有实测结果，也不是已达到的承诺**。首次实验固定设备型号、系统/浏览器版本、服务器资源、生产构建和样本，随后基于瓶颈调整方案；改变预算需说明原因。

| 测量 | 建议起始预算与边界 |
| --- | --- |
| 输入、发送、切换的本地视觉反馈 | p95 ≤ 100 ms，独立于网络与模型响应 |
| 冷开到首批历史可读且输入可用 | p95 ≤ 3 s；受控网络为下行 10 Mbps、上行 1 Mbps、RTT 150 ms，另测实际链路 |
| 事件已被浏览器接收到对应绘制 | p95 ≤ 100 ms；服务器可发到绘制的全链路延迟另外记录，避免混入模型生成时间 |
| 短断线后的可信状态恢复 | 网络重新可达且页面前台后 p95 ≤ 3 s；过期游标的快照恢复单列 |
| 普通索引/历史读取及操作受理 | 服务端处理 p95 ≤ 100 ms；不含网络、密码散列、附件处理或原生执行等待 |
| 慢端和重复恢复 | 每个缓冲有明确上限；循环断连后连接/监听器回落，内存不随轮次持续增长 |

初始样本建议包含 10,000 条历史消息、单条 100 KiB 长回复、3 段同时输出的对话、2 台设备及 6 个标签页。它们是负载实验数据，不是产品上限；历史应分页加载。记录样本生成方式、至少 100 次交互/短恢复及 30 次冷开分布，分别报告桌面与真实 Android，保留异常尾部而不只报平均值。

同时记录事件循环延迟、数据库操作时长、队列长度/字节数、CPU/内存、首屏资源及长任务。先测量再定位：短查询不能因返回 Promise 就被视为不阻塞；编辑器、阅读器和大正文也不能无条件进入首屏包或反复全量渲染。

## 更新通道的决策实验

HTTP + SSE 与 HTTP + WebSocket 使用同一确定性事件源、操作记录、快照/游标协议、样本和生产构建；先隔离传输变量，不依赖模型调用制造负载。少量真实 Harness 验收另行确认原生映射，替身通过不能代替它。

覆盖直连与实际反向代理/Tunnel，记录浏览器入口协议和代理到源站的协议；检查流式缓冲、缓存、压缩、心跳与超时。使用桌面和真实 Android，注入输出中断、黑洞连接、Wi-Fi/移动网络切换、收命令后丢响应、慢接收、游标过期、应用重启、后台回前台及多标签页竞争。观察正常关闭和异常断开的资源释放。

先满足正确性，再比较首条更新延迟、恢复时间、资源消耗与实现复杂度，更新 ADR 的结论。若 SSE 在实际链路满足预算，采用 SSE；若 WS 对已复现问题有明确收益，采用 WS。Next.js 只在首屏/导航出现需解决的瓶颈时做同样本对照，避免为选型先实现两套工作台。

真实设备或部署入口暂不可用时，保留该项未验证状态；桌面手机视口与网络模拟只能证明其覆盖的范围。结果附版本、环境、脚本和原始测量位置，留在对应 PR/CI；本文只维护长期验收契约。
