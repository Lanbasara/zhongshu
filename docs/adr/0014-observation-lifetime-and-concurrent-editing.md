# 观察生命周期独立于原生工作，普通编辑不停止 Agent

## 决策与范围

用户确认将历史读取、事件观察、原生驻留与执行分别处理；优先修复观察恢复，再将文件编辑与 Host 停机解耦，并以真实子 Agent 和后台任务连续性验证后部署 PRE。本决定替代 [ADR 0011](0011-managed-workspace-execution.md) 中普通文件编辑必须取得全运行组独占窗口的要求，保留持久操作身份、执行授权和管理操作的协调边界。

## 生命周期

- 浏览器查看历史只读取持久视图及有界历史，不自动恢复原生 Agent。启动按未完成执行、队列和未知操作恢复观察，不按最近访问或固定数量历史激活。
- 实时观察属于需要跟踪的工作；连接代次失效后清理旧句柄，重建事件订阅并同步。状态查询成功不能冒充事件流恢复，重连不授权重发输入。
- 观察容量不足不等于原生执行失败或结果未知。历史读取不占用执行观察槽位。
- 释放观察与卸载执行是不同能力。只有 adapter 明确声明释放不会终止原生工作时，工作台才可回收空闲观察；父轮 idle 不证明子 Agent 或后台进程结束。
- 受管 Codex Host 保留其已激活线程的原生订阅，外部工作台释放 listener 不调用原生 unsubscribe；DSH 释放 follow 监听不 dispose Host Agent。中书网关和页面连接不拥有这份原生执行生命周期。

这是保守的工作保护策略，不是原生内存回收方案。已执行会话的 Host 驻留仍需按版本和真实资源测量单独优化；不声称 16 个观察槽位限制了原生 Agent 数，不按“7 天没聊天”或父 idle 强制回收。不承诺 Host 本身退出后后台进程仍可原地续跑。直接兼容连接若未提供安全释放能力，不推断其与专用 Host 相同。

## 文件编辑

普通编辑不关闭执行入口、不等待全工作区空闲、不停止 Host。在线条件保存继续验证登记目录身份、路径、内容大小、读取版本及保存操作身份；保存意图和结果进入独立 writer 日志，未知结果只核对，不自动重写。

接受并发写入的取舍：中书自己的保存相互串行、拒绝可检测的旧版本；检测到冲突时保留稿件，提供重新读取和比较路径。文件版本检查与原子替换不能约束任意外部进程，因此不宣称全局文件 CAS 或全工作区独占。原生工具自己的版本/上下文检查是独立保护，不是全局锁。

旧版本留下的独占窗口保留明确恢复入口，未决保存先核对；新文件编辑不能建立窗口。移除工作区及显式 Host/插件管理仍走其管理协议，不能在文件编辑改动中绕过授权或重置账本。

## 验证归属

[接续地图](../features/continuity.md)维护冷读、恢复及订阅连续性；[文件地图](../features/workspace-files.md)维护并发保存和真实 child/background 路径。原生固定版本对应的源码、正负控及部署证据在 PR/仓库外保留；公开 App Server 的机制不等于桌面前端的全部私有策略。
