# 自动任务新建的执行对话默认完全访问

用户确认 Codex 和 DSH 的日程自动任务都默认完全访问。工作区读写下，Codex 定时运行曾停在 `zhongshu.record_result` 的工具审批。

- **新建执行对话。** Codex 调度器使用完全访问和 `never` 审批，模型与思考深度继续沿用默认值。DSH 原生调度协议仅接收工作目录和 Agent 预设，运行时使用操作者为 DSH Web Host 配置的完全访问默认预设。两端都在实际投递时创建对话。
- **既有会话。** 显式投递到既有对话沿用该对话的权限。旧版 Codex「首次新开后复用」任务若仍绑定未归档的任务专用工作区读写对话，下一次投递新建完全访问对话后继续复用，原任务、原对话和历次记录保留；已经提交的投递继续沿原对话完成。DSH 原生已经创建的会话沿用其持久化权限。
- **权限归属。** 中书手动新对话显式选择权限。完全访问影响原生工具审批，用户提问仍按 [ADR 0016](0016-questions-and-approvals.md) 处理。

本决定更新 [ADR 0021](0021-automations.md) 和 [ADR 0026](0026-shared-agent-capabilities.md) 中自动新建对话的权限默认。
