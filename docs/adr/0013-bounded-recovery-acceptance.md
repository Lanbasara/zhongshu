# 正常负载保持性能，超载与原生故障以保护和有界恢复验收

## 背景与确认

2026-11-05，用户暂停发散的极限实验，并确认本轮剩余目标：正常使用流畅；极端资源压力下允许原生 Harness 失败，但必须保全已存内容和任务身份、遵守编辑门禁，并提供可操作的恢复。完成五项固定验证后给出明确上线结论，不继续扩展故障排列、平台或规模；不影响当前 VPS 实例。

本决定收敛 [ADR 0010](0010-durable-reading-archive.md)、[ADR 0011](0011-managed-workspace-execution.md) 和 [ADR 0012](0012-bounded-data-paths.md) 的验收范围，不改变正文保管、授权、未知操作不重派和人工保存保护的承诺。

## 决策

- 正常约定工作量仍满足延迟与资源预算；正常负载频繁崩溃不合格。超出承载范围允许背压、暂停后台推进或进程失败，失败不等于任务完成或数据已保存。
- 原生恢复由持有持久门禁的控制器决定，沿原容器、原数据和原绑定进行。编辑、收束、恢复意图未知时不得由旁路自动启动；Docker 无条件重启不能替代该许可。
- 自动恢复次数与退避有上限。超过上限或身份、配置、执行结果无法核实时，保持明确不可用并提供显式恢复路径；不清账本、不重新创建对话、不重发未知操作来换取成功。
- 存储 worker 致命失败使网关停止受理并退出，由外部有限重启策略重开同一数据。普通背压或事务拒绝不触发进程重启。
- 永久正文增长与临时资源、观察账本增长分别计量。容量保护不等于磁盘寿命承诺，验收需说明实际增长成本和适用资源配置。

## 固定退出范围

本轮仅完成五项：实例资源预算下的正常长对话及大量对话；Codex 进程故障恢复；DSH 进程故障恢复；网关重启与编辑门禁保护；容量压力及解除。具体动作与停止条件归[联合工作单](../spec/long-term-performance.md)。

原 40/1,000 段真实原生对话编辑扩展与更广故障组合保留为诊断资料，不继续作为本轮新增硬门槛。已有大规模合成产品路径、真实双端编辑和原生存档证据按实际代码影响复用；不得把替身或本地限额称为目标 VPS 原生环境实测。

完成范围内实现后冻结一个候选，执行固定验收。必验项失败则本轮结论为不通过，记录触发条件与影响，不自动开启新一轮架构改造。范围外问题先记录。源码、类型、测试、构建、文档和独立执行的既有仓库要求保持不变。

## 取舍

本轮证明明确资源条件下的可用性、数据保护与恢复，不承诺所有原生版本、所有崩溃时刻和多年无故障。代价是过载或未知状态下可能暂时不能执行，需要等待或操作者处置；已有存档和操作身份不能因此丢失。
