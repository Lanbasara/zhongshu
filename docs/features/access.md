# 私人入口：feature map

范围：单管理员登录、身份恢复与退出。账号和会话契约归[身份说明](../identity.md)，管理员备份恢复沿[实例地图](instance.md)。

## 用户入口与子能力

打开应用进入“登录中书”，填写“管理员密码”，点“进入工作台”；已登录时从侧栏“退出登录”。没有公开注册或浏览器密码重置入口。

| 子能力 | 本次怎样驱动与判断 |
| --- | --- |
| 初始化前与首次登录 | 在全新临时数据目录启动，确认“管理员尚未完成初始化”；按可信 CLI 初始化，再重开页面登录，看到工作台。错误密码保留登录页且没有私有内容 |
| 刷新与普通重启 | 登录后刷新，再只重启本次中书进程并重开页面；有效身份保留。记录浏览器与数据目录身份，避免把重新登录当成恢复 |
| 多端与退出 | 两个独立浏览器上下文分别登录。A 退出后回到登录页，其私有请求拒绝、对应 SSE 不再返回新私有内容；B 仍可访问。刷新 A 核对没有复活；确认退出后本标签页草稿清除 |
| 重置与过期 | 本次隔离 CLI 重置后，两个端的私有请求/流都失效。绝对过期用可控时间的回归检查；没有真实跨时长观察时不声称已完成浏览器过期验收 |
| 登录状态竞争 | 有能力控制响应顺序时，延迟旧的 session 查询，再登录/退出并释放旧响应；页面不得退回旧身份。只做一次顺序登录不能证明此分支 |

## 前提、证据与定位

按[通用验证能力](../verification.md)准备全新数据与独立浏览器上下文；本页不需要真实 Harness。重置、限速与异常身份检查只在自己的测试实例执行。页面操作证据配合私有 API 的状态码、SSE 是否关闭以及另一端实际状态；不保存密码、Cookie 或 CSRF 值。

页面显示工作台但 API 未鉴权，属于服务端边界问题；API 已正确切换而页面退回旧状态，沿浏览器身份代次排查。退出时旧内容消失不单独证明服务端会话已吊销。

## 容易误判的地方

- 同一浏览器上下文的两个标签页共享 Cookie，不能用它们代替两个独立登录端。
- 回环 HTTP 开发例外不证明公网 TLS、Secure Cookie 或 Android 的表现；容器检查的范围见[开发流程](../development.md)。
- 确认退出会清除草稿；断网、回执未知时的草稿保护属于[接续地图](continuity.md)，不能用退出测试替代。
