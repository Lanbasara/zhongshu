# 工作区文件阅读与编辑

## Sub-features

- 可编辑格式为 UTF-8 的 Markdown、TXT、JSON、YAML、TOML、INI，上限 256 KiB。Markdown 可预览当前稿件；超过 64 KiB 时默认打开原文，按需分页渲染预览。HTML 和 HTM 只读，上限 1 MiB。报告保留支持的结构、样式、静态 SVG 与嵌入位图。脚本和网络资源不加载。
- 目录仅接受已登记工作区内的相对路径。列表隐藏隐藏项与符号链接，文件内容拒绝符号链接、硬链接和特殊文件。目录一次最多显示 200 项。
- 写入要求操作者满足 [managedWrites 配置前提](../../README.md#harness-connections)。相交目录内全部已关联对话都须经过原生空闲核对。等待、排队、失联、结果未知或仍保留中断状态时暂停保存。保存时检查版本，同一旧版本的后续提交会被拒绝。
- DSH 工作区点「编辑」进入维护模式。中书先确认空闲并禁止新执行，控制器确认专用 Host 退出后才开放编辑。维护门禁单独查询原生状态及任务终态，聊天正文同步由对话路径处理。保存成功、退出编辑或返回对话时恢复原 Host。浏览器直接关闭时维护状态保留，重新打开阅读器可点「恢复 Agent」。
- 草稿留在当前页面内存。保存被拒绝时保留稿件。「重新打开」会在确认放弃草稿后读取远程版本。

## How to get to it (user POV)

在已登录工作台的侧栏选择「工作区文件」。进入阅读器后，点顶部文件名按钮展开或收起文件列表浮层。选择文件后浮层关闭。桌面可并排或展开，手机从全屏阅读器返回对话。工作区可切换，已有对话仅用于预选所属工作区。

## Driving it with Harness

遵循[共同入口](README.md#独立执行验收)。fixture 可从[标准启动入口](README.md#launch从干净克隆开始)启动，合成工作区位于本次 root 的 `workspace-a` 和 `workspace-b`，已启用条件保存。真实 Codex 与 DSH 按[真实 Host 前提](README.md#native真实接入分支)各跑一轮。使用全新的合成工作区和管理员会话，准备 Markdown、TXT、一个配置文件及一份有长文、宽表、图形的自包含报告。报告放在子目录，分别链接一个存在、一个不存在和一个越界的底稿。以测试专用的合成私有请求和脚本标记检查报告隔离。

1. 从桌面和手机侧栏打开报告，核对版式和可读内容。从滚动后的位置点开工作区内的底稿，再返回，观察原位置。拒绝越界和不存在的目标，报告不发出私有请求，脚本标记不出现。
2. 双页面打开同一 Markdown 版本。在一端编辑、预览、保存，独立检查原文件字节并在另一页面重读。另一端保存旧版本时核对冲突、草稿及磁盘仍是先保存的版本。另测试 TXT、配置样本和 HTML 只读。
3. Codex 和 DSH 分别从同一工作区的另一段对话执行可观察的合成任务。运行时保持阅读，核对编辑不可用、未保存稿保留，直接调用保存也被拒绝。空闲后分别验证未变更可保存和已变更触发冲突。验证执行与保存竞争、失联及停止后的拒绝行为。
4. 核验实例能否启用原地保存时，另在自有隔离工作区驱动有超时上限的后台写入工具。让父命令退出、原生对话回到空闲，独立核对子进程仍存活且能否在手动保存后写回文件。用实际 PID、工作目录和磁盘字节区分原生空闲与写入已收束。在 DSH 上进入编辑后，核对容器和写入进程确实退出，保存后尝试释放旧工具，磁盘仍须保留手动内容。退出编辑，核对原生会话身份和同会话下一轮。暂停或恢复结果未知时，核对保存和派发均被拒绝。

5. 性能复验用 1、20、100 段同工作区对话及接近 256 KiB 的文本。分别测点击反馈、原生空闲核对、Host 退出和文件读回。核对门禁没有调用聊天历史同步、隐藏标签页停止轮询、支持 Web Locks 的同浏览器可见页共享兜底查询、Markdown 原文和预览往返后选区与滚动保持。使用超长单行配置和含中文、表格及代码块的 Markdown，保存后独立核对字节。

## Gotchas

原生轮次状态与独立进程是否仍在写入分别核对。容器隔离工作区外的文件，仍需另外约束工作区内的后台写入。保存成功以实际文件字节为准。

## Implementation and regression

定向回归入口为 `node --test test/resources.test.ts test/workbench.test.ts`。它验证认证、CSRF、路径、只读类型、旧版本和发送竞争的服务端行为，原生状态使用替身。真实浏览器及两个原生 Host 各自留证。
