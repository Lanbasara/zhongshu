# 多年容量、存储调度与恢复

属于[上线前联合规格](long-term-performance.md)。容量与永久存档政策归 [ADR 0010](../adr/0010-durable-reading-archive.md)，有界存储和操作身份归 [ADR 0012](../adr/0012-bounded-data-paths.md)，身份及恢复边界遵循 [ADR 0006](../adr/0006-auth-session-data.md)。

## 用户路径与行为

| 场景 | 可观察结果 |
| --- | --- |
| 按年累计对话、历史、工作区和操作 | 不因累计条数达到旧常量而失去新增、同步或接续能力；分页与搜索覆盖尚未加载内容 |
| 大量后台同步与维护并行 | 受理、停止、终态持久化和用户读取保持预算，后台任务公平推进，队列和缓存不无界增长 |
| 接近配额或磁盘阈值 | 提前可见告警，达到准入阈值拒绝新增工作和上传，保留旧正文与管理入口 |
| 已受理任务仍在执行 | 不因容量自动取消；优先记录状态与结果，写失败明确显示且不推进存档完整性 |
| 扩容、重启或恢复备份 | 恢复原任务和身份、核对未决原生效果，不自动重派；数据完整性可独立检查 |

## 验收

- 跨过 10,000 段对话、单段 50,000 条历史、256 个工作区及操作/队列的原累计阈值；在百万条历史总量下追加、前插、翻页和搜索。查询计划及实际访问量证明常规操作不扫描全量索引/正文，不能只调大常量。
- 在单写者压力下并行受理、同步、目录刷新和阅读，验证优先级、后台公平性、队列背压及主循环响应；一般写页不能触发全对话重排，必要重建期间旧索引可读。
- 分别触发应用配额、实际磁盘余量门禁和真实 ENOSPC；观察正文、WAL、暂存块及预留空间。旧内容可读、不自动删除，未提交数据不报已保存，已受理任务不被容量逻辑取消。释放空间后按回差恢复准入与续传。
- 压缩已结束操作记录后重试同 ID 同内容与同 ID 不同内容，前者读回旧结果、后者拒绝，均不产生新原生副作用；未知操作及资源引用不能被回收。
- 从旧库迁移并比对全部已存正文、资源引用和绑定；在正文分块提交、任务进度更新期间备份，恢复到新目录后校验引用和摘要。旧会话失效、未决操作待核实；旧程序打开新 schema 被拒绝。
- 按联合规格固定的持续运行条件观察内存、WAL、缓存、任务和数据库增长，区分永久数据正常增长与可回收资源泄漏。完成后更新[访问与数据地图](../features/access.md)及受影响的接续/管理地图。
