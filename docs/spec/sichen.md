# 司辰：时间模块与命令行

边界与取舍见 [ADR 0022](../adr/0022-sichen-time-module.md)。名字「司辰」、命令 `sichen` 由用户 2026-11-09 选定。

| 用户行为 | 可观察结果 |
| --- | --- |
| Agent 建定时任务 | 在 shell 里运行 `sichen schedule add`，时间用日期和钟点写；建好后打印任务编号、规则描述、接下来三次运行时间（上海时间，带"明天 / N 天后"）、结束日期和结果放哪。输入不合法时用中文说明哪里错，不建任务 |
| 结束日期 | 每天、每周、每月的任务都能设结束日期（`--until`，含当天），命令行和网页都能设。DSH 到期后自己结束任务；卡片写"到 YYYY-MM-DD"；日历只排到结束日期 |
| 回到本对话 | `--to 本对话` 投递到正在运行命令的那段对话（由 `DSH_SESSION_ID` 认出）；不在 DSH 的 shell 里运行时报错 |
| 管理任务 | `list`、`show`、`edit`、`pause`、`resume`、`delete`、`run`。修改和删除带冲突检查，别处改过时拒绝并说明 |
| 日历条目 | `sichen timeline add / done / cancel / list` 读写当前工作区的 `.zhongshu/timeline.jsonl`，检查日期、类型和链接；`remind-set` 改用它 |
| Agent 知道有它 | 中书 MCP 服务的说明里写着"定时任务与日历条目用 `sichen`，先看 `sichen --help`"；实例上 DSH 原生定时任务工具关闭 |
| 安装与更新 | `sichen --version` 与中书版本一致；中书换版本，司辰跟着换；版本不一致时拒绝并说明；`sichen doctor` 和实例体检能看出命令不在、版本不符或连不上 |

不做：另造调度器、交易日历（节假日跳过）、Codex 自动任务、条件触发、读写滴答。

## 时间写法

| 写法 | 含义 |
| --- | --- |
| `--at "2026-11-10 21:40"` | 一次 |
| `--every 每天 --time 09:00` | 每天 |
| `--every 工作日 --time 14:45` | 周一到周五 |
| `--every 周一,周三 --time 10:00`（也接受 `mon,wed`） | 每周的这几天 |
| `--monthly 15 --time 10:00`；加 `--months 3,6,9,12` | 每月几号；只在这些月 |
| `--cron "0 10 30 3,6,9,12 *"` | 高级写法，原样交给 DSH |
| `--from 2026-11-10`、`--until 2027-01-31` | 从哪天开始、到哪天结束（含当天），可选 |
| `--tz Asia/Shanghai` | 时区，默认取本机时区（VPS 上是上海） |

## 命令清单（首批）

```
sichen schedule add <名称> (--prompt <文本> | --prompt-file <文件>) <时间写法> --to 本对话|新对话|首次新开
sichen schedule list [--状态 开启|暂停|结束|全部] [--json]
sichen schedule show <编号> [--json]
sichen schedule edit <编号> [--name …] [--prompt … | --prompt-file …] [时间写法] [--until … | --no-until]
sichen schedule pause|resume|delete|run <编号>
sichen timeline add <操作|大事|决定|研究> <标题> (--at "日期 钟点" | --date 日期) [--link 工作区内路径] [--detail …] [--id …]
sichen timeline done|cancel <编号>
sichen timeline list [--from 日期] [--to 日期]
sichen doctor
sichen --version | --help
```

## 实现要点

- **模块**：`src/sichen/` 下分两层。
  - 时间模块：纯函数，零依赖，中书服务端和网页都引用它；负责解析、检查、换算、算出接下来几次、描述。
  - 命令行：只用 Node 自带的库，构建成可直接运行的文件。
- **服务端**：在 Agent 工具端点（回环地址、同一令牌）上加 `/sichen/v1/…`。
  - 每个请求带协议版本；版本不一致返回明确错误。
  - 有结束日期时换算成带 `UNTIL` 的 `rrule`。
  - 投递目标：`本对话` 用会话编号；`新对话` 和 `首次新开` 用命令所在目录对应的已登记工作区。
- **读回**：DSH 返回的 `rrule`，只要是这个模块写出的那几种，就还原成每天、每周、每月加结束日期，用来显示和铺日历；认不出的照原样显示。
- **网页**：新建表单和卡片加"结束日期"，并改用同一个时间模块。
- **实例**（操作者层）：
  - 维护脚本把中书镜像里的 `sichen` 只读放进 DSH 容器的 PATH；
  - 令牌文件只读挂入；
  - 在 DSH 配置里关闭原生定时任务工具；
  - 体检时运行 `sichen doctor`。
- **中书 MCP 服务**在 `initialize` 里返回说明。

- **单元测试**：
  - 时间写法的解析与拒绝：不存在的日期、已过的时间、结束早于开始、错误的星期写法；
  - 换算出的 `rrule` 与描述；
  - 接下来几次运行，包括跨月、跨年和结束日期当天；
  - 读回还原；
  - 协议版本不一致；
  - 时间轴的写入与校验。
- **预发实例真实路径**：

  - `timeline add` 写入的条目出现在日历上；
  - 在网页上设结束日期；
  - 换掉 `sichen` 版本，看是否被拒绝；
  - `doctor` 与实例体检。
- **正式环境数据**：
