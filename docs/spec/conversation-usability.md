# 对话基本可用性

## Goal

先把现有对话打磨到可以日常使用，再扩展其他能力。来源：2026-11-02 用户试用反馈、align 方向确认及本轮 specify 的原文件引用确认。需求已确认；用户通过 implement 授权实施，联合工程验证后仍待用户试用确认。

## Users and stories

读懂正文和执行过程，使用文字、图片与引用表达任务，离开后可接续。术语沿用[领域语言](../../CONTEXT.md)，执行边界沿用 [ADR 0001](../adr/0001-native-harness-boundary.md)。

## Scope / Non-goals

| 范围 | 可观察行为与边界 |
| --- | --- |
| 正文与版式 | Markdown、GFM 表格/任务列表、链接、代码高亮与复制；围栏内部保持源码。统一字号、宽度、间距和层级，长内容不撑破页面，流式与历史含义一致。 |
| 工具过程 | 按轮组织可折叠过程，摘要可辨认动作、状态和关键结果，展开查看命令/输出/错误；原生信息不编造，不能只有同名“工具活动”。 |
| 图片 | 选取/粘贴/拖放上传，发送前预览/移除，上传失败可重试；正文/附件图片可查看放大。两端真实接收图片；已有原生生成能力的输出可查看，刷新/重启后仍可回看，不以“已生成”文字代替。各端生成能力分别核实，不新增原生生成工具。 |
| 输入 | 自动增高，发送/停止/不可发送状态清晰；失败保留文字、附件与引用，不静默降级成纯文本。保留 Enter 换行、⌘/Ctrl+Enter 发送。 |
| 引用 | 消息选段保留所选文字与来源；`@` 选择当前工作区原文件，Agent 读取时以文件实际内容为准，不冻结发送时内容或承诺恢复旧版本。引用可预览/移除；文件删除/不可读明确反馈。 |

不包含 HTML/交互报告、通用编辑/文档附件、跨对话引用、语音、运行中追加或审批。模型/权限按对话固定。遵循[身份边界](../adr/0006-auth-session-data.md)与[操作恢复约定](../adr/0004-recoverable-communication.md)。

## Implementation decisions

以下为 2026-11-02 已确认的实施安排；按完整 feature 统一集成与验收。技术未知见[前置探测](integration-probes.md)，完成判据见下节，不另建计划或进度文件。

| 切片 / 依赖 | 可交付结果与完成关口 |
| --- | --- |
| P0 风险探测 / 首先 | 独立现场用最小页面贯通认证入口→图片输入→真实 Host→实际输出资源→刷新回看；两端分别记录，不用模拟成功替代。并核实工具字段、组件状态适配，确定资源权限/存储/回收与既有备份/恢复的一致性及依赖；需要架构取舍时先确认 ADR。 |
| P1 阅读与排版 / P0 的 UI 结论 | 用 [shadcn/ui AI Elements](https://ui.shadcn.com/docs/ai-elements) 与 [Streamdown](https://streamdown.ai/) 的候选组合改善真实既有对话；正文/围栏/代码复制/窄屏可读，输入外观统一，原有发送门禁与草稿恢复不变。可先于资源链路独立交付。 |
| P2 消息兼容与工具 / P0 的协议结论 | 协调 adapter、持久/实时历史和公开 schema，保留必要工具结构并在页面按轮展示；旧数据库/纯文本历史迁移可读，真实成功/失败工具与展示对应，SSE/重连不重复或丢条目。 |
| P3 图片收发 / P0 资源结论 + P2 | 受认证的资源登记/读取、受限 Host 传入及生成输出采集，接最小可用附件输入；通过真实识图、输出字节核对、刷新/重启和越权反例。失败保留草稿，未知操作仍持有资源，未引用资源才可回收。 |
| P4 输入与引用 / P1 + P3 | 完成粘贴/拖放/预览/移除/重试和消息选段、`@` 原文件；选择/提交/读取校验工作区权限。独立核对实际输入及原文件新内容，涵盖删除/失权；切换对话和回执丢失不串草稿、不另派发。 |
| P5 联合验收 / P1–P4 | 同一候选版本完成两端真实对话、窄屏、应用/Host 重启、既有创建/发送/停止/恢复回归及用户试用。各实现 PR 同步地图；全部通过才关闭本切片。 |

契约由共享 schema 与 Harness 类型共同约束；adapter 解释原生字段，Workbench/存储维护操作与资源关联，前端只消费授权内容。P1 与 P2 可分支独立推进；发送/资源/草稿契约的修改统一集成，当前不安排多个 Agent。工程改动统一走分支 PR，集成不代表发布。严格 schema 的生产者/消费者须同版本配套；先兼容读取旧文本再迁移使用方，验证后才删兼容路径；这不承诺旧二进制能读取新数据库。

## Testing decisions

整组能力使用唯一的[对话基本可用性 feature map](../features/conversation-usability.md)：U01 完整旅程与 U02–U10 分支共同验收，不按实现切片分别签收。恶意内容不能执行脚本或取得应用身份；资源授权、操作恢复与旧对话兼容不得退化。四项检查及[既有回归](../features/README.md)通过并保存独立证据后，仍须用户实际试用确认基本可用。地图维护实际入口与证伪路线，不以地图存在签收。

## Open questions

没有待用户决定的范围问题。原生图片通道、工作区原文件语义与现有恢复协议已贯通；实际模块、资源限制与寿命归 [architecture](../architecture.md)，当前验证入口归唯一 feature map。用户试用确认仍为退出条件；若需扩大权限、缩减范围或改变边界，再带影响讨论。
