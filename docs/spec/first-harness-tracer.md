# 首条 Agent 曳光弹：完成真实工作，离开后接续

## Goal

同一套中书界面分别选择 Codex 或 DSH，完成一段真实工作；关闭页面或中断中书后回来，恢复同一对话、输出和状态；需要时停止当前轮。

## Users and stories

- 作为用户，我可以选择 Codex 或 DSH 创建对话，并在一轮真实工作中读取工作区文件、写入成果。
- 作为用户，我关掉页面后 Agent 继续工作，重新打开时看到真实状态和完整内容。
- 作为用户，我可以在原对话中追问，模型、权限和原生上下文保持不变。
- 作为用户，我可以在运行中停止当前轮，并知道“已中断”不等于所有后台工具都已退出。

## Scope

- 私人入口 → 创建对话 → 真实工作/追问/停止 → 离开后接续。
- 两个 Harness 的真实原生绑定、操作记录、历史分页和有界恢复。

## Non-goals

- 运行中追加、完整提问/审批。
- 任意工作区管理、附件、成果阅读与编辑。
- 生产发布；发布由操作者独立发起。

## Current state

- 产品路径已在 `main` 实现，并合入 PR #5；DSH 首条消息问题由 PR #6 修复。
- 本机真实账号路径已验证：两个 Harness 读取并写入文件、同会话接续、关页和中书进程中断后恢复、显式停止。
- 显式停止只确认原生本轮中断；后台工具可能继续运行，界面必须如实提示。

## Remaining

- 真实原生 Host 崩溃后的产品恢复路径。
- Android 真机：中文输入、键盘、后台/页面回收、移动网络切换。
- VPS/Tunnel 真实代理链路。
- 完整性能样本与 p95 预算。
- 生产发布与发布后的公网验证。

## Implementation decisions

- 两个 adapter 实现同一 `HarnessAdapter` 语义；原生字段与版本差异留在 adapter 内。
- 发送先在 SQLite 记录稳定操作编号，再派发；未知回执只核对，不盲目重发。
- 已接受与已完成分开；同一对话需核实上一条消息的原生终态后才能发送下一轮。
- 历史使用稳定条目身份和持久水位；恢复窗口有界，缺口明确暴露。

## Testing decisions

- 使用真实浏览器、真实 Fastify、SQLite 和独立原生 Host；合成工作区，不读个人业务资料。
- 两个 Harness 分别记录结果；本机通过不替代 Android、代理或性能验收。
- 证据保留版本、环境、动作、观察和清理状态，放在 PR/CI 或操作者实验记录中。
