# 大目录与工作区导航

属于[上线前联合规格](long-term-performance.md)。沿用[工作区管理](workspace-management.md)、[对话管理](workspace-conversation-management.md)及[文件阅读](workspace-file-reading-editing.md)的入口和权限；目录代次与有界查询由 [ADR 0012](../adr/0012-bounded-data-paths.md) 定义。

## 用户路径与行为

| 场景 | 可观察结果 |
| --- | --- |
| 首次打开大目录 | 分批扫描并显示进度，已发现部分不伪装完整；能取得完整清单后继续翻页 |
| 反复翻页或刷新 | 同一代次排序稳定；刷新期间上一个已完成清单仍可读，完成后明确切换；过期游标要求刷新 |
| 文件新增、删除、改名 | 清单可以显示需要刷新；重新扫描后反映变化，打开旧项时按真实文件状态处理 |
| 工作区很多或尚未展开 | 工作区、对话及原文件选择入口均可分页/搜索，不全量加载所有分组才查找旧内容 |
| 打开、引用、保存文件 | 按真实目录身份、路径和版本核对，清单记录不授予越界、隐藏项或链接访问能力 |

## 验收

- 分别准备 201、10,000 个符合现有可见规则的目录项，独立生成期望集合。稳定目录逐页读完，集合相等且无重复；目录前部有大量被过滤项时，后续合法项仍可到达。
- 在扫描和翻页期间确定性新增、删除及改名，验证部分/完整状态、固定代次、旧清单可读、新代次切换和过期行为。不能用每页重扫无序目录后跳过 N 项实现分页。
- 强杀扫描进程后重启，旧已发布代次不损坏，未完成代次不会误报完整；监听漏事件后通过重新扫描发现变化。只对稳定目录声明完整，不承诺普通文件系统的瞬时快照。
- 超过旧工作区阈值，搜索未加载且没有对话的工作区，展开旧对话并打开文件；同时检查新建、`@` 原文件引用等选择器，不留仍被旧截断限制卡住的入口。
- 在索引生成后替换目录、删除文件或植入链接，文件访问和保存仍拒绝不符合既有边界的目标。扫描、索引缓存和响应均有字节/批次预算，更新[文件地图](../features/workspace-files.md)与[工作区地图](../features/workspace-management.md)。

## 实施条件

实施任务为 [P6](https://github.com/Lanbasara/zhongshu/issues/30)，在 P2 的存储契约上推进，可与存档及阅读界面并行；阅读器、输入区引用、工作区目录选择器和列表导航一起迁移，不能只修一个截断入口。

完整目录扫描允许后台 O(N) 工作，但不在每次前台翻页重复，也不把全部清单载入请求内存。预算与设备条件、联合运行和退出条件统一归联合规格。
