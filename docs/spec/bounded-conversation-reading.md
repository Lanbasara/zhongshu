# 有界对话阅读与完整正文入口

属于[上线前联合规格](long-term-performance.md)。沿用[对话基本可用性](conversation-usability.md)的 Markdown、工具、图片和引用语义；巨型内容有限预览与全文入口按 [ADR 0012](../adr/0012-bounded-data-paths.md)，永久正文按 [ADR 0010](../adr/0010-durable-reading-archive.md)。

## 用户路径与行为

| 场景 | 可观察结果 |
| --- | --- |
| 打开或翻阅长对话 | 读取有界摘要页，保持阅读锚点并可回到最新；不一次加载全对话，也不先传全文再截断 |
| 单条回复超出展示预算 | 显示明确预览、正文大小与完整阅读入口；普通回复保留富文本，预览不能改写存档 |
| 打开全文 | 按版本分块读取；可到达末尾，超长行、巨型表格或代码不会强迫整份解析；极端内容可使用原文阅读 |
| 复制或下载全文 | 内容来自完整正文，复制成功时必须完整，不能静默复制预览；下载流式传输，取消能释放资源 |
| 输入、流式输出和反复切换 | 输入不触发全部正文重渲染，当前输出只更新有限尾部，缓存与 DOM 形成上限；旧响应不串对话 |

## 验收

- 分别准备大量小消息、82 条复杂消息、单条 1 MiB 及超过原正文上限的可获取回复；包含中文跨块、极长单行、巨表、围栏代码和工具输出。网络实际字节与挂载量受预算约束，不能只数可见条目。
- 在固定浏览器与 4 倍 CPU 降速下测首屏、输入、滚动、全文切换及长任务；同一视口增加后台历史总量后不新增全量传输或解析。按联合规格冻结的延迟及内存阈值签收。
- 原文独立生成并校验长度/摘要；跨块到尾、复制、下载逐字相同。正文版本更新、取消下载、读取失败及重复请求均不拼接多个版本，失败不报成功。
- 连续加载旧页、返回最新和切换大量对话，观察缓存、DOM 与堆的稳定上限。进行中流式内容超预算后存档仍继续，完成后全文一致；同时输入并验证输入内容不丢失。
- 保持原有 Markdown/图片/引用、工具折叠、键盘与窄屏操作；覆盖旧页锚点和迟到响应。真实两端内容走通，更新[对话地图](../features/conversation-usability.md)及[接续地图](../features/continuity.md)。

## 实施条件

页、预览、结构和正文块预算是共同约束；仅采用虚拟列表或 CSS 隐藏不能通过。原生大载荷导入也必须满足接入边界，具体预算与设备条件由联合规格统一冻结。
