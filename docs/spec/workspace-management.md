# 工作区管理

依据 2026-11-03 的工作区范围对齐。管理员在本地和 VPS 实例使用同一套入口管理[工作区登记](../../CONTEXT.md)。目录属于当前连接的实例，选择范围由操作者预先开放，遵循[原生执行边界](../adr/0001-native-harness-boundary.md)。

| 用户动作 | 可观察结果 |
| --- | --- |
| 添加工作区 | 在侧栏打开目录选择器，在当前实例开放的范围内选择已有文件夹，或新建一个空文件夹并添加。添加后无需重启即可选择该工作区、浏览其文件，并用已接入的 Codex 或 DSH 创建对话。区域之外的目录须先由操作者接入。 |
| 改名、置顶和搜索 | 改名只更新中书显示名。置顶让工作区排在未置顶项之前，且同一实例的其他设备可见。工作区搜索匹配显示名或目录名，包含没有对话的工作区。现有对话标题搜索仍可单独使用。 |
| 从中书移除工作区 | 停用登记并从常用列表、新建对话和文件选择器移出。在「已移除的工作区」仍可按原归属打开中书已保存的对话历史和附件。磁盘目录与文件、对话和 Harness 原生会话都保留。通过该登记发送消息或打开原文件须先恢复。 |
| 恢复工作区 | 恢复原登记身份并核对原目录和原生绑定，再开放对应的接续能力。原目录缺失、被替换或绑定无法核实时，提示原因并阻止受影响的接续。例如原位置出现同名新文件夹，旧对话不能仅凭路径相同就在新目录运行。 |

有对话正在运行、等待输入或结果尚未核实时，移除应提示原因并保留入口，用户可回到原对话处理。此切片管理中书登记，目录的重命名、移动和删除，以及 Harness 挂载与权限调整属于实例文件或部署管理。

## 验收

- 在本地和 VPS 分别添加一个已有目录和一个新建空目录，无需重启。分别用真实 Codex 和 DSH 创建对话并完成一轮文件任务，独立读回实际文件，核对没有落进另一目录。越界目录不能被浏览或登记。
- 搜到无对话的工作区，改显示名、置顶并取消置顶。刷新或从同一实例的另一个设备打开，核对显示名和置顶结果，原目录和已有对话归属保持一致。
- 移除有历史和附件的工作区，刷新并重启后核对入口变化、历史可读和磁盘文件内容。尝试从旧对话发送或通过该登记读取原文件，服务端须拒绝。对运行中、等待输入、结果待核实，以及发送与移除并发的场景，核对用户仍能处理已受理的工作。
- 恢复后分别在 Codex 和 DSH 接续原对话，核对原生会话身份和文件结果。用合成目录覆盖原目录缺失和被同名目录替换，核对提示和受影响的接续被拒绝。升级前已有的工作区和对话也须保持可达。
- 实现后更新对应功能地图，按[独立执行验收](../features/README.md#独立执行验收)取得证据。
