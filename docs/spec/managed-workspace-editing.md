# 受管工作区编辑

用户已确认普通编辑与停机解耦，以 [ADR 0014](../adr/0014-observation-lifetime-and-concurrent-editing.md) 替代原独占编辑要求。沿用[文件阅读与编辑](workspace-file-reading-editing.md)的格式、稿件与阅读范围。移除工作区及显式 Host/插件管理仍遵守 [ADR 0011](../adr/0011-managed-workspace-execution.md)；本切片不扩展管理协议。

## 用户路径与行为

| 动作或故障 | 可观察结果 |
| --- | --- |
| 进入编辑 | 直接显示编辑器，不扫描全部对话、不等待空闲、不关闭执行入口或停止 Host |
| Agent 运行、等待或状态未知 | 编辑不改变其生命周期；子 Agent、后台任务和队列继续按原生语义工作 |
| 保存文件 | 验证目录身份、路径及读取版本；应用保存串行，意图与结果持久记录 |
| 远程版本已变化 | 拒绝可检测的旧版本保存，保留本地稿件，提供重新读取与比较路径 |
| 保存回执未知 | 核实同一保存操作；不得自动重写，任意外部写者不受全局锁约束 |
| 结束编辑、返回对话或关闭页面 | 不停止或恢复 Host；稿件沿用原浏览器生命周期 |
| 打开旧版独占窗口 | 保留明确的恢复入口，未决保存先核对，恢复原 Host 数据与对话绑定；新编辑不建立窗口 |

## 验收

- Codex 与 DSH 均验证运行中真实页面保存、独立文件读回，以及子 Agent、后台任务实际完成；不能只用父轮 idle 或 Host PID 证明连续性。
- 覆盖关页、空闲观察释放、重开与断线重连；恢复订阅不得重发原输入，原生执行与页面观察分离。
- 两页保存同一旧版本只允许先满足条件者成功，另一份稿件保留；原生写者改动已打开文件时，验证可检测冲突。并发写入的边界按 ADR 0014 说明，不承诺全局 CAS。
- 保存未决时拒绝冲突的管理冻结/移除；应用恢复后核实原保存身份，外部内容不同保持未知而不重写。
- 旧应用建立窗口后，保留原库升级，走页面恢复、原对话接续与直接编辑路径。真实驱动和两个独立执行者入口归[文件功能地图](../features/workspace-files.md)。

原规模证据保留其版本和条件；本轮不据小规模连续性测试宣称完成[长期性能规格](long-term-performance.md)的全部容量或延迟预算。原先独占窗口的历史取舍保留于 ADR 0011 与 Git 历史，不作为并发编辑的验收目标。
