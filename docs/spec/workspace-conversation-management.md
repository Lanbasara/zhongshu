# 工作区与对话管理

## 目标与范围

在中书侧栏按已登记的[工作区](../../CONTEXT.md)组织和管理对话。来源为 2026-11-03 的范围对齐与实施设计讨论。视觉以中书 HTML 交互原型为唯一设计依据，Codex 和 DSH 截图用于参考工作区分组。此切片沿用既有登记方式，新增、改名和移除归[工作区管理](workspace-management.md)，文件操作归[工作区文件阅读与编辑](workspace-file-reading-editing.md)。

## 用户行为

| 能力 | 可观察行为 |
| --- | --- |
| 侧栏 | 桌面宽度在用户调整后固定，刷新恢复所选宽度。长标题单行省略，选中、运行状态和操作入口仍可辨认，打开对话可看到完整标题。手机使用抽屉访问同一套管理操作。 |
| 工作区导航 | 展示已登记的工作区，包括暂无对话的工作区。可折叠每组并独立展开更早的对话。组内新建预选该工作区，仍可选择 Codex 或 DSH。打开已有对话进入原历史与接续路径。 |
| 重命名与搜索 | 重命名更新中书显示的标题。按标题跨工作区搜索，结果标明工作区，覆盖尚未展开的旧对话。默认搜索未归档对话，可切换查看已归档对话。 |
| 归档与恢复 | 归档后从主列表移入归档视图，仍可打开原历史。恢复后回到主列表并可继续原对话。归档保留对话与原生会话的绑定。运行中或等待用户输入的对话留在主列表，尝试归档时给出原因。 |

## 验收

- 在两个有对话的工作区和一个空工作区核对分组。展开其中一组的旧对话，打开并看到既有历史，再从空组新建并核对归属。
- 以尚未加载的旧对话验证标题搜索。在结果中重命名，刷新或从第二个页面打开，核对新标题与同一段历史。
- 归档一段可归档的对话，核对主列表、归档视图及两种搜索范围。重启应用后仍可从归档视图打开原历史，恢复后可继续原对话。Codex 和 DSH 各核对一次原生会话身份与接续结果。另验证运行中、等待输入以及双页面发送与归档交错时，进行中的工作仍可到达。
- 用长标题核对默认宽度、调整后宽度、刷新和窄窗口。手机从抽屉走通搜索、归档恢复与返回正文。
- 按[共同验证入口](../features/README.md#独立执行验收)取得独立执行证据，覆盖升级前已有对话，并通过仓库规定的四项检查。实现后更新相应功能地图。

## 实施待验证

沿用现有工作区与对话身份。旧库归属和历史可达性、分页与搜索的稳定性、归档与新提交的并发判定须在实现中验证。具体宽度、分页大小、排序及持久化方案属于工程安排。
