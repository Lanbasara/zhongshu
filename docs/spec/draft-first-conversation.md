# 新对话草稿与思考深度

## Goal

落实 [ADR 0010](../adr/0010-draft-first-conversation.md)：取消新建弹窗，首次发送才创建，优化输入区并补齐 Codex 思考深度；保持已有输入、执行与恢复能力。依据为 2026-11-06 用户对交互的逐轮修订及本次正式化要求。当前按已确认范围实施；本工作单不代表已完成验收。

## Users and stories

- 工作区内点“新对话”，直接进入带该工作区的输入草稿；输入与配置修改不产生历史条目或原生会话。
- 全局“新对话”直接进入草稿。优先使用有效的浏览器本地继承记录；首次访问、记录缺失或格式失效时，从已有工作区与对话历史兜底。普通浏览器升级不强制清除有效记录。
- 整个实例尚无可用工作区时，页面明确提示“先添加工作区”，提供添加入口并禁用发送，不弹出新建对话表单或创建空对话。添加成功后选中该工作区并保留已输入文字；取消或失败时仍可重试。
- 用户在输入框底栏独立选择 Power，在同一组合面板内选择模型、调节离散深度、选择默认或复位；权限另选。首次发送后沿用固定配置。

## Scope / Non-goals

覆盖新建入口、草稿、首次创建与发送衔接、能力目录、配置持久化/兼容、两端 adapter、相关共享组件和 Storybook。继续支持图片、文件引用、技能、中文输入与快捷键；Codex 可在草稿选技能，DSH 原生目录需要已有会话，草稿明确提示“首次发送后可选择技能”，已有对话继续支持技能；回归已有对话的发送、停止、队列、刷新接续和用量显示。不增加运行中配置切换、新 Harness、通用附件、语音、模型生成标题或生产发布。

## Implementation decisions

长期身份与失败约束以 ADR 0010 为准；现有能力入口见[创建](../features/conversations.md)、[输入与恢复](../features/conversation-usability.md)、[执行](../features/execution.md)、[界面组件](../architecture.md#界面与设计系统)。

- 继承采用浏览器本地偏好，不为此新增服务端偏好存储；工作区入口按该工作区继承，全局入口带入本浏览器最近确认发送的工作区与配置。服务端历史只在本地记录缺失时用于初始兜底，不覆盖已编辑草稿；所有预选都须重新核验实际目录，不能把缓存当授权或静默提升权限。
- 无工作区分支复用[工作区管理](../features/workspace-management.md)的添加能力：在操作者允许的目录内添加已有目录或创建目录，不要求必须新建文件夹。无允许目录根或配置未就绪时提示管理员配置，不能展示不可完成的创建按钮；历史工作区已移除也不能被兜底自动恢复。完成工作区添加仍不创建对话，后续首次发送遵守同一创建边界。
- 输入区保持紧凑：Power、模型/深度、权限置于同一底栏；模型控件无常驻灰色胶囊底，交互反馈与相邻控件一致。组合面板包含模型入口、原生支持的离散档位和复位，不重复列出同一模型的深度组合；支持键盘、焦点返回与窄屏操作。探索入口为 Storybook「设计探索/新对话与思考深度」，示例数据不可作为产品默认值。
- 创建前可切换 Power；两端配置分开维护并按真实目录核验。工作区/Power 变化导致材料、技能或权限不适用时，保留文字并明确指出，不静默丢材料、改选更高权限或携带另一端的标识发送。
- 默认采用当前 Power 实际提供的有效默认模型及该模型默认深度；缺少可靠默认时要求用户明确选择，不猜测。复位仅恢复当前 Power 的默认模型与深度，不修改工作区、Power、权限或正文；首次发送固定实际配置。
- 初始标题截取用户首条文字的固定长度，不调用模型总结；具体截断长度属实现细节，避免截断 Unicode 字符或产生多行标题。用户可从侧栏对话菜单重命名，编辑、取消、保存并刷新后保持结果；后续发送和恢复不覆盖手动名称。无文字首发使用“新对话”。
- 首发须展示创建、准备、材料处理、发送及失败/待核对状态；重复点击、刷新、超时不能重复创建或派发。冻结后的配置及材料不能被后续界面修改替换；未知结果核实前不允许以新配置重试同一次提交。
- 深度来自实际模型能力并真实作用于原生执行，不能只更新标签。创建、后续轮次和恢复均须核验配置；旧格式可恢复且不被新默认覆盖。图片在草稿到真实对话的交接中遵守现有大小、存储、身份与授权限制。

## Testing decisions

| 验收 | 可观察结果与证据 |
| --- | --- |
| N01 无副作用进入 | 工作区/全局入口、输入、切 Power 均不增加服务端对话或原生会话；首次发送后只有一段对话及一次首发；文字首发生成截取标题，重命名取消不变、保存后刷新保留，后续轮次不覆盖 |
| N07 首次使用与继承 | 零工作区进入全局新建，提示添加且禁止发送；取消/失败无空对话，成功选中工作区并保稿；无目录根有明确配置提示。有效缓存优先，清缓存/首次访问按历史兜底，无历史不伪造默认；失效目录/权限不能绕过校验 |
| N02 配置真实生效 | Codex 与 DSH 分别选非默认模型/深度并完成任务，独立核对原生配置及首轮、后续轮和刷新恢复；不支持的组合服务端拒绝，默认/复位不跨 Power |
| N03 首发材料完整 | 文字、图片、文件引用与技能的适用组合实际到达对应 Harness；切工作区/Power、上传失败和存储失败保稿，不降级成仅发文字 |
| N04 故障恢复 | 分别丢创建回执、首发回执，在准备/材料阶段刷新或中断应用；沿原身份恢复，未知不自动重复派发，已绑定失败不另建；用操作与原生记录核对，不能只看气泡 |
| N05 兼容与回归 | 升级前两端对话仍可接续，原配置不变；图片/引用、技能、用量、停止、队列和恢复按现有地图复跑，未覆盖项明确列出 |
| N06 界面与交付 | 桌面和窄屏真实操作并截图核对底栏、面板、键盘/中文输入和失败提示；无遮挡/横向溢出；四项仓库检查通过，更新受影响 feature maps，按共同入口独立执行验收并由用户试用确认 |

## 已确认的恢复规则

- 历史兜底按最近成功发送的对话取值，不按创建时间；没有对话历史时，唯一可用工作区自动选中，多个则要求选择。
- 每标签页、每工作区保留一份草稿；切换和刷新可恢复，不承诺关闭标签页后的长期恢复。缓存不构成授权，格式损坏、配额不足或存储被禁用时明确提示，不能假称已保存。
- 无文字首发的初始标题为“新对话”。

## 当前验证边界

已取得两端真实首发及 high 深度原生回读、DSH 刷新后接续、Codex 图片/原文件/技能混合首发，以及两位独立执行者的草稿、恢复、首次使用、配置联动和窄屏证据。四项仓库检查通过。原型截图不替代这些执行证据。

工作单保持 active，等待用户试用。完整原生 Host 崩溃矩阵、Android 真机和本轮未复跑的停止/队列分支不声明通过。Codex 原生空线程冷恢复可能丢失尚未首轮持久化的权限/深度；当前继续按配置不一致阻断，不能自动覆盖权限或改建新会话掩盖此限制。
