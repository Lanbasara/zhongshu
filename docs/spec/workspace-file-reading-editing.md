# 工作区文件阅读与编辑

本轮范围修订：普通文件编辑不再要求停机或独占运行组，以 [ADR 0014](../adr/0014-observation-lifetime-and-concurrent-editing.md) 为准；下文旧门禁要求仅适用于遗留窗口恢复及管理操作，不作为新编辑的验收目标。

在已登记的[工作区](../../CONTEXT.md)查阅文件、阅读 HTML 成果和手动修改少量纯文本文件。以 2026-11-03 的需求对齐为准，历史需求来自 2026-10-29《中书 PRD》的文件交互章节。中书 HTML 交互原型是唯一界面设计依据。

后续范围已确认：[受管工作区编辑](managed-workspace-editing.md) 将本页的空闲条件保存扩展为两个 Harness 的独占编辑窗口，[目录与导航](workspace-directory-index.md) 承担大目录完整访问。编辑资格、执行竞争和规模退出条件以这两份规格为准；本页继续维护文件格式、阅读、草稿与版本冲突，当前实现仍见功能地图。

| 用户行为 | 可观察结果 |
| --- | --- |
| 浏览与打开文件 | 从「工作区文件」进入阅读器。顶部文件名按钮展开或收起文件列表浮层。桌面可与对话并排阅读及展开，手机使用独立阅读页并可返回对话。Agent 工作期间仍可查阅。 |
| 阅读 HTML | HTML 在阅读器中按报告版式显示，操作为只读。报告可通过相对链接打开同一工作区内受支持的文件。例如 `reports/summary.html` 中的 `../notes/source.md` 打开 `notes/source.md`，返回时恢复报告原阅读位置。目标不存在或超出工作区边界时明确提示。 |
| 编辑纯文本 | 取得有效编辑窗口后可编辑 Markdown、TXT 和少量常用纯文本配置文件。Markdown 可在原文和当前稿件的预览之间切换。显式保存写回远程原文件，未保存稿留在当前页面，离开时提示。 |
| 工作状态与冲突 | Agent 工作期间编辑和保存不可用。取得编辑窗口后，相关新执行由服务端门禁阻止；门禁失效或无法核实时保留当前稿件并暂停保存。再次保存前核对打开版本，远程已变化则提示并保留稿件，避免静默覆盖。 |

原有 DSH 专用 Host 维护约定已被 [ADR 0011](../adr/0011-managed-workspace-execution.md) 的统一门禁协议扩展；恢复仍保留原生数据和对话绑定，暂停或恢复无法确认时保留稿件并拒绝写入与派发。目标协议尚未全部实现，不能把新约定当成当前配置能力。

## 验收

- 在桌面和手机从工作区目录打开真实 HTML 报告，核对版式、长文、宽表和图形。点击相对链接打开正确底稿并返回原阅读位置。覆盖不存在及越界目标，验证报告内容无法获得应用身份或调用私有接口。
- 修改 Markdown，核对预览跟随未保存稿，离开有提示。保存后由另一页面重新打开并独立核对远程文件内容。对 TXT 和选定的纯文本配置样本验证写回，对 HTML 验证只读。
- 分别用 Codex 与 DSH 验证 Agent 工作期间仍可读，编辑不可用，直接发起保存也被服务端拒绝。按受管编辑规格覆盖申请窗口时已有工作、窗口内新派发被拒绝和门禁失效保稿；再次取得窗口后，远程版本未变时可保存、已变时提示冲突。
- 从两个页面打开同一旧版本，先保存一份，再提交另一份。核对后者保留未保存稿，远程仍是先保存的内容。按[共同验证入口](../features/README.md#独立执行验收)取得独立证据并更新功能地图。

## 验证范围

当前格式、大小限制、HTML 渲染边界和复跑入口见[功能地图](../features/workspace-files.md)。真实 Harness、桌面 Chrome 和窄屏已取得运行证据。手机真机与中文输入法仍待验证。DSH 规模测量覆盖原生会话数增长，尚未覆盖所有会话均有长历史的负载。
