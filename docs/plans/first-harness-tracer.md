# 首条 Agent 曳光弹：完成真实工作，离开后接续

状态：产品路径已实现，按本地真实运行、可控故障与目标设备/部署链路分别验收。实际实现归[架构地图](../architecture.md)，连接与行为边界归 [Harness 接入](../harnesses.md)，逐版本证据归 PR/CI；本计划只保留验收范围和未覆盖项。

## 用户路径

同一套中书界面分别选择 Codex 或 DSH；每个 Harness 使用独立但内容相同的合成工作区，避免相互改写结果。

1. 登录，选择工作区、原生可用模型与权限，创建配置固定的对话。
2. 读取 `notes.md` 的三条事实，写入 `result.md`；观察正文、工具活动与状态，独立核对磁盘文件。
3. 在受控工具仍运行时关闭页面；重新打开、从另一端进入或重启中书后，恢复同一原生会话的历史与结果。
4. 在原会话追问仅上一轮提供的标记，确认上下文和配置保持。
5. 启动另一个受控任务，显式停止，核对原生终态和实际工具进程；停止不承诺撤销已经产生的效果。

私人入口已实现，使用与数据恢复见[身份说明](../identity.md)。前置原生实验和协议测试不能替代上述浏览器路径。运行中追加、完整提问/审批、任意工作区管理、附件与成果阅读仍留在后续切片。

## 故障与质量验收

| 场景 | 应观察到的结果 |
| --- | --- |
| 发送回执丢失、同编号重试 | 只核对同一操作；不能确认时保留输入和待核实状态，不盲目重派 |
| 重连期间持续输出 | 正文与状态均能前进；历史无重复，旧响应不覆盖新会话 |
| 运行中关页、应用中断 | 原生工作独立继续或明确报告限制；恢复读取不创建替代会话 |
| 原生停止、等待或故障 | 状态与原生事实一致；不支持的交互不静默批准，保留队列如实展示 |
| 空会话及部分创建失败 | 已取得的绑定保留，配置核实后才允许发送；空历史不等于读取失败 |
| 历史分页、长正文、慢端 | 字节、队列与连接数量有界；超界明确恢复而非假装连续 |
| 会话退出、过期或重置 | 私有接口与更新流失效；不再返回新的私有内容 |

真实 Android 的中文输入、键盘、后台/页面回收及移动网络切换，VPS/Tunnel 的真实代理链路，以及[质量要求](../quality.md)中的完整样本与 p95 预算必须分别记录。在这些环境未运行前，保留“未验收”；桌面手机视口、合成事件和本机通过不能替代它们。HTTP + SSE 当前实现与通道定案的区别见 [ADR 0004](../adr/0004-recoverable-communication.md)。
