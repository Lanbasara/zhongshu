私人入口已实现，使用与数据恢复见[身份说明](../identity.md)。前置原生实验和协议测试不能替代上述浏览器路径。运行中追加、完整提问/审批、任意工作区管理、附件与成果阅读仍留在后续切片。

## 剩余验收

故障分支按各地图与本轮修改选择，真实原生 Host 崩溃后的产品路径仍需独立验收，不能由中书进程中断的结果代替。原生账号在 VPS 的登录、连接交接、权限与进程监管需实例配置完成后再走同一组合路径。
