# 单管理员私人入口：交接

状态：已实现，是[首条 Agent 曳光弹](first-harness-tracer.md)的身份与持久化前置步骤。管理员可以登录、刷新后恢复有效身份并退出；初始化、密码重置、一致备份与新目录恢复由可信终端执行。公开健康与版本接口继续可用。

实际模块归[架构地图](../architecture.md)，账号、会话和数据操作归[身份与数据操作](../identity.md)，本地与容器验证入口归[开发流程](../development.md)。这些文档与代码维护当前行为，本页不重复参数和操作步骤。

本次 PR 保存接口、数据库、生产构建浏览器与 Compose 容器的检查结果及环境范围。Android 真机和部署后的 TLS 链路不在本次验收范围；容器内的 HTTPS origin 与 Secure Cookie 检查不能替代真实浏览器 TLS 验收。生产初始化与发布仍由操作者独立发起。

下一步继续首条 Agent 曳光弹的两端原生绑定、真实工作及恢复路径；私人入口完成不代表 Agent 运行、流式更新或文件能力已经成立。
